# ISM6427 — Weather

A simple glassmorphic weather app powered by the free [Open-Meteo API](https://open-meteo.com/) (no API key needed). Defaults to Boca Raton, FL; use the search bar to look up any city.

## Files
- `index.html` — markup
- `style.css` — glassmorphism styles
- `app.js` — fetches and renders weather

## Deploy to Netlify
It's a static site with no build step. Drag the folder into Netlify, or connect the repo with **Build command** empty and **Publish directory** set to `/`.
